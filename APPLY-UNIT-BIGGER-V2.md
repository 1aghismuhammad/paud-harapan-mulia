# APPLY — Unit Pendidikan Bigger V2

Extract ZIP ke root project dan overwrite file yang sama.

Kemudian:

```cmd
php artisan optimize:clear
```

Pastikan:

```cmd
php artisan serve
```

dan:

```cmd
npm run dev
```

Hard refresh:

```text
Ctrl + Shift + R
```

Expected desktop:
- PAUD dan TK menjadi sekitar 330×330px;
- label PAUD/TK lebih besar;
- gap antar-card sedikit lebih lega;
- section tetap centered dan responsive.
