# Change Log — TK Match PAUD V4

## Objective

Menyamakan design language halaman TK dengan halaman PAUD versi terbaru yang sudah disetujui.

## TK Now Matches PAUD In

### Hero
- same section spacing
- same large unit hero composition
- same floating unit label treatment

### Profile
- centered eyebrow + large heading
- two portrait photos
- brand-green accent bar behind profile images
- same desktop width and spacing
- same image hover behavior
- same typography scale

### Showcase Sections
Fasilitas, Aktivitas, dan Pembiasaan sekarang sama dengan PAUD:

- stacked decorative panels
- brand accent bar
- floating white category label
- carousel gallery
- 3 cards desktop
- 2 cards tablet
- 1 card mobile
- previous/next circular arrows
- touch swipe
- hover/focus dark overlay
- title appears only on hover/focus
- image zoom and card lift on hover

### Berita
