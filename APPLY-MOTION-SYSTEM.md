# Apply — Phase 1I Motion & Interaction System

Extract this ZIP directly into the repository root and overwrite the included files.

Then run:

```bash
php artisan optimize:clear
npm run build
php artisan test
```

During development:

```bash
npm run dev
php artisan serve
```

Hard-refresh the browser after applying:

- Windows/Linux: `Ctrl + Shift + R`

The patch adds no package/dependency.
