# APPLY — Visi & Misi Image Hover

Extract ZIP ke root project dan overwrite file yang sama.

Kemudian:

```cmd
php artisan optimize:clear
```

Pastikan development server aktif:

```cmd
php artisan serve
```

dan:

```cmd
npm run dev
```

Hard refresh:

```text
Ctrl + Shift + R
```

Hover mouse ke masing-masing foto.

Expected:
- foto naik sedikit;
- shadow lebih jelas;
- foto zoom halus;
- tint hijau tipis muncul di bagian bawah;
- layout tidak bergeser.
