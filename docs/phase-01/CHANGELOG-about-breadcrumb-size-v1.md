# About Breadcrumb Size V1

## Summary
Menyamakan ukuran breadcrumb tab pada halaman Sejarah dan Visi & Misi dengan breadcrumb tab halaman Fasilitas pada viewport desktop.

## Files changed
- `resources/css/app.css`

## Changes
- Desktop breadcrumb radius: 6px -> 8px.
- Desktop horizontal padding: 28px -> 32px.
- Desktop vertical padding: 20px -> 22px.
- Desktop breadcrumb font size: 10px -> 12px.
- Mobile/tablet behavior dan layout tidak diubah.

## Database impact
None.

## Route impact
None.

## Dependency impact
None.

## Risk
LOW.

## What was NOT changed
- Page hero height.
- Content halaman Sejarah.
- Content halaman Visi & Misi.
- Halaman Fasilitas.
- Navbar/footer.
